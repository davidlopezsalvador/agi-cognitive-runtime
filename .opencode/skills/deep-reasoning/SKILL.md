# Deep Reasoning Skill

Specialized skill for deep reasoning tasks.

## When to Use

- Complex logical reasoning
- Multi-step inference
- Causal analysis
- Analogical reasoning
- Abstract thinking

## Operators

- ABSTRACT: Extract patterns from specifics
- ANALOGIZE: Find structural similarities
- GENERALIZE: Form general rules from instances
- SPECIALIZE: Apply general rules to specific cases
- INFER: Draw conclusions from evidence
- DEDUCE: Logical deduction
- INDUCE: Inductive reasoning
- ABDUCE: Abductive reasoning (inference to best explanation)

## Process

```
1. Gather observations
2. Look for patterns
3. Form abstractions
4. Find analogies
5. Draw inferences
6. Test conclusions
7. Refine understanding
```

## Anti-Patterns

- Jumping to conclusions without evidence
- Confusing correlation with causation
- Ignoring counter-evidence
- Over-generalizing from limited examples
