# Experimentation Skill

Specialized skill for designing and executing experiments.

## When to Use

- Testing hypotheses
- Distinguishing between competing explanations
- Validating assumptions
- Empirical investigation

## Process

```
1. IDENTIFY what is uncertain
2. FORMULATE hypotheses
3. DESIGN experiments that distinguish hypotheses
4. EXECUTE experiments
5. OBSERVE results
6. UPDATE confidence
7. REPEAT if needed
```

## Experiment Design Principles

- **Information Value**: Prefer experiments that provide the most information.
- **Cost**: Consider time, resources, and risk.
- **Distinguishability**: Choose experiments that best separate hypotheses.
- **Independence**: When possible, run independent experiments.

## Heuristic

> Prefer actions with high expected information gain relative to cost and risk.
