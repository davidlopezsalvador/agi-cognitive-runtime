# Memory Skill

Specialized skill for memory management.

## Memory Types

### Working Memory
Temporary state for the current reasoning process.
- Current goal
- Active constraints
- Current plan
- Active hypotheses
- Recent observations

### Episodic Memory
Stores experiences with context, actions, results, and lessons.

### Semantic Memory
Stores generalized knowledge extracted from experiences.

### Procedural Memory
Stores reusable skills and procedures.

### Failure Memory
Stores what went wrong and why.

## Consolidation

Not every interaction should be permanently stored.
Importance evaluation:
1. Was this merely an event?
2. Did this teach something reusable?
3. Can the lesson be generalized?

## Retrieval

When retrieving from memory:
- Consider task relevance, not just similarity
- Prefer memories that helped solve similar problems
- Check failure memory before reusing strategies
