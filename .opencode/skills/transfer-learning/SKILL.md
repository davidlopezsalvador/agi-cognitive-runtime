# Transfer Learning Skill

Specialized skill for cross-domain knowledge transfer.

## Core Question

> Have I encountered a structurally similar problem before?

Not: "Have I seen the exact same question?"

## Process

```
1. ABSTRACT the problem to its structure
2. SEARCH for structurally similar past problems
3. IDENTIFY transferable elements
4. ADAPT to the new domain
5. VERIFY the transfer works
```

## Structural Similarity

Look for shared patterns:
- Same causal structure
- Same type of reasoning required
- Same failure modes
- Same solution strategies

## Example

- Software debugging ↔ Electronic troubleshooting
- Scientific diagnosis ↔ Organizational failure analysis
- Database optimization ↔ Traffic flow optimization

The shared abstraction is what transfers, not the surface details.
