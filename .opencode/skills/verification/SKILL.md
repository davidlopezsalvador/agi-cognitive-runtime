# Verification Skill

Specialized skill for independent verification.

## When to Use

- After reaching a conclusion
- Before presenting important results
- When the stakes are high
- When assumptions are uncertain

## Verification Questions

- What could make this wrong?
- Which assumption is least certain?
- What evidence contradicts this?
- Did I solve the requested problem?
- Did I introduce side effects?
- What edge cases remain?
- Can I reproduce the result?
- Can I independently verify it?
- What would falsify my conclusion?

## Process

```
1. IDENTIFY claims to verify
2. GATHER independent evidence
3. CHECK assumptions
4. LOOK for contradictions
5. TEST edge cases
6. ASSESS confidence
7. DOCUMENT verification result
```

## Independence

Verification should be independent from generation where practical.
The verifier should not assume the generator's conclusion is correct.
