# Research Skill

Specialized skill for research tasks.

## When to Use

- Gathering information from multiple sources
- Investigating unknown topics
- Evaluating competing claims
- Building comprehensive understanding

## Process

```
1. DEFINE the research question
2. IDENTIFY information sources
3. GATHER evidence
4. EVALUATE source quality
5. SYNTHESIZE findings
6. ASSESS confidence
7. IDENTIFY gaps
8. DOCUMENT results
```

## Evidence Quality

Rate evidence:
- **Strong**: Multiple independent sources agree
- **Moderate**: Single reliable source
- **Weak**: Single source, unverified
- **Contradicted**: Sources disagree

## Uncertainty Tracking

Always track:
- What is known
- What is suspected
- What is unknown
- What evidence would change the assessment
