# /investigate Command

Hypothesis-driven investigation for uncertain problems.

## Usage

```
/investigate <problem>
```

## Behavior

1. Observes the problem
2. Generates candidate hypotheses
3. Ranks hypotheses by plausibility
4. Designs experiments to distinguish them
5. Executes experiments
6. Updates confidence
7. Identifies probable cause

## Examples

```
/investigate Why does the queue processing lag at peak hours?
/investigate What causes the sporadic test failures in CI?
/investigate Why is the ML model accuracy degrading over time?
```
