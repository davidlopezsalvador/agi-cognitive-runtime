# /agi Command

General AGI-mode task execution.

## Usage

```
/agi <task description>
```

## Behavior

1. Classifies the task's cognitive requirements
2. Retrieves relevant knowledge and experience
3. Determines appropriate cognitive depth
4. Executes using the cognitive loop
5. Verifies important conclusions
6. Extracts reusable lessons

## Examples

```
/agi Investigate why the API returns intermittent 500 errors
/agi Design a caching strategy for the user service
/agi Find the root cause of memory leaks in production
```
