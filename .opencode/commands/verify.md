# /verify Command

Independent verification of claims and conclusions.

## Usage

```
/verify <claim>
```

## Behavior

1. Identifies the claim to verify
2. Gathers independent evidence
3. Checks all assumptions
4. Looks for contradictions
5. Tests edge cases
6. Reports verification result

## Examples

```
/verify The fix resolves the race condition without introducing regressions
/verify The new architecture supports 10x current traffic
/verify The migration script handles all edge cases
```
