# /research Command

Research mode for gathering and synthesizing information.

## Usage

```
/research <question>
```

## Behavior

1. Defines the research question
2. Identifies information sources
3. Gathers evidence from multiple sources
4. Evaluates source quality
5. Synthesizes findings
6. Assesses confidence levels
7. Identifies knowledge gaps

## Examples

```
/research What are the trade-offs between consistency and availability in distributed systems?
/research How do modern garbage collectors handle generational heaps?
/research What are best practices for zero-downtime deployments?
```
