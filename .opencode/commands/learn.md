# /learn Command

Extract reusable lessons from the current session.

## Usage

```
/learn
```

## Behavior

1. Reviews the current session's activities
2. Identifies successful strategies
3. Identifies failure modes
4. Extracts generalizable lessons
5. Stores lessons in memory
6. Suggests procedural improvements

## Output

- Successful strategies worth reusing
- Failure patterns to avoid
- General principles discovered
- Procedural improvements suggested
